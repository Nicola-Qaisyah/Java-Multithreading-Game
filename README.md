# Java Multithreading Game

A Java-based multiplayer game developed using multithreading and TCP socket communication.

## Overview

This project implements a multiplayer game in which multiple users can connect and interact with each other through network communication.

The application uses Java multithreading to handle multiple client connections concurrently, while TCP sockets provide communication between the server and clients.

## Key Features

- Multiplayer communication over TCP.
- Concurrent client handling using multithreading.
- Client-server architecture.
- Real-time communication between connected users.

## Technologies Used

- Java
- TCP Sockets
- Multithreading
- IntelliJ IDEA
